Each page in this section solves one common automation job with machines and belts. It states the problem, shows the answer running on a board, gives the Factory code, and says what the answer costs and where it stops.

## Move and copy events

- [Forward a webhook to another URL](forward-a-webhook/): receive a webhook and send it on with an HTTP Sink.
- [Send a webhook to multiple URLs](send-to-multiple-urls/): copy one webhook to two endpoints with a Tee.
- [Combine several sources with Merge](combine-several-sources/): bring webhooks from two Sources onto one line.

## Shape events

- [Transform a JSON payload](transform-json-payload/): rename, add and drop fields in a Factory.
- [Filter events](filter-events/): keep the items you want and drop the rest.
- [Split an array into items](split-an-array/): turn one order into one item per line item.

## Route events

- [Route by content](route-by-content/): send items down different belts by what they hold.
- [Split traffic with seeded randomness](split-traffic/): send a share of items down a second line, the same way on every replay.

## Pace and spread the work

- [Spread work across parallel workers](parallel-workers/): share one job between two Factories.
- [Buffer events behind a slow step](buffer-events/): let a burst wait on a long belt.
- [Rate limit with belt pace](rate-limit/): cap how fast items reach an HTTP Sink.
- [Run on a schedule every N ticks](run-on-a-schedule/): make an item on a timer and act on it.

## Handle failures

- [Send failures to a dead letter queue](dead-letter-queue/): send each machine's faults to a Debug Sink you can read.
